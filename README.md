# Attendance Planner

A single-page attendance planning dashboard for the ten supplied class sections.

This project includes subject-level forecasts, attendance health visuals, an OD/medical-leave simulator, an in-browser advisor, and the original section timetable scans.

The app saves attendance inputs in your browser's local storage. Forecasts assume weekdays follow the entered timetable and do not account for holidays or cancelled classes. Check your institution's leave rules before relying on an estimate.
